# Documentation Archive

This directory contains explanatory documents for models or analyses that have
been superseded. Archived material is retained for provenance and dissertation
development history; it is not current implementation guidance.

Frozen preregistrations and their audit records remain in
`docs/preregistration/`, even when the corresponding experiment failed or was
superseded. Their original locations are part of the reproducibility record.

For the current executable path, start with:

- `README.md`
- `docs/repository-map.md`
- `configs/README.md`
- `docs/changelog.md`
